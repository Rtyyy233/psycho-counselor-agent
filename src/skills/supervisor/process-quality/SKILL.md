# 谘商过程质量监测（Process Quality Monitoring）

参考来源：Sommers-Flanagan 第4章（倾听技术）+ 第5章（提问与指导性行动技术）+ 第6章（循证关系变量）+ Falender & Shafranske 第3章（技术胜任力）+ Ivey微技能层级模型

## 核心评估框架

### Ivey微技能层级模型

督导需评估受训者在每一层级的掌握程度：

```
出席行为 → 提问 → 鼓励 → 重述/释义 →
情感反映 → 总结 → 聚焦 → 面质 →
解释 → 信息给予/教导
```

### 非指导性到指导性的连续体

```
沉默 → 重述 → 澄清 → 情感反映 → 总结 →
情感验证 → 解释性情感反映 → 解释 → 重构 → 面质
```

## 监测维度

### 维度一：出席行为质量

**SOLER模型**（Ivey & Ivey）：
- **S**quarely face — 正面面对
- **O**pen posture — 开放的身体姿态
- **L**ean slightly forward — 微微前倾
- **E**ye contact — 适度的眼神接触（因文化而异）
- **R**elaxed — 放松自然

**副语言特征**（音高、语调、音量、语速、流畅度）显著影响来访者对共情和可信度的感知。语音质量是先于内容的、来访者首先接收到的信息。

**五种负面出席行为**：
1. **过度点头** — 显得机械、不真诚
2. **过度"嗯嗯"**（20次/2分钟） — 表面化、未经思考的回应
3. **不当眼神接触** — 被审视感或回避（需考虑文化差异）
4. **鹦鹉学舌式复述（Parroting）** — 精确重复而不加处理，感觉像被分析
5. **笨拙模仿（Mimicking）** — 机械模仿而非自然同步，引发阻抗

### 维度二：倾听技术质量

**重述/内容反映的四个层级**：
1. 基础重述 — 反映事实内容
2. 感官重述 — 强调感官细节，使体验更生动
3. 隐喻重述 — 使用来访者自己的隐喻，深入其意义世界
4. 建构主义/解决导向重述 — 强调优势和例外

**情感反映的层级**：
1. **初级共情** — 反映来访者明确表达的情感：'听起来你感到很沮丧'
2. **高级共情** — 反映来访者隐含的、未直接表达的情感：'我听到你说这些的时候，好像还有一丝不甘心在里面'

**四种常见的失败共情回应**（Sommers-Flanagan）：
1. "我理解你的感受" — 来访者可能怀疑：你怎么可能知道？→ 取代以反映而非声称理解
2. "我也经历过类似的事" — 焦点转移到治疗师 → 先共情，考虑是否必要自我表露
3. "天哪，那一定太可怕了" — 施加评判 → 用反映代替评价："听起来那对你来说非常可怕"
4. "哦，你真可怜" / "你一定很坚强才能承受这些" — 评价性赞扬可能抑制进一步袒露

**沉默管理**：
- 四种沉默：创造性沉默（内在加工）、保护性沉默（感到不安全）、焦虑性沉默（不知道说什么）、抗拒性沉默（不愿意参与）
- 关键原则：不要急于填充沉默——沉默是来访者处理深层体验的时间
- 当沉默过长或来访者明显不适时：温和邀请——"刚才沉默的时候你心里在想什么？"

**言语追踪（Verbal Tracking）**：
- 遵循来访者的叙事线而不转换话题
- 走神信号：跳到自己的想法或评价上，而非跟随来访者的内容

### 维度三：提问技术质量

**五条提问原则**：
1. 用开放式问题开启探索
2. 用封闭式问题获取特定、必要的事实
3. 避免引导性问题（"你当时感到愤怒，是吗？"→ 中立："你当时是什么感受？"）
4. 避免听起来像指责的"为什么"问题（"你为什么那样做？"→ "是什么导致了那个决定？"）
5. 跟随来访者的回应，而非遵循预设的问题议程

**提问类型矩阵**：

| 类型 | 定义 | 正例 | 反例（陷阱） |
|------|------|------|------------|
| 开放式 | 不能以是/否回答 | '你能多说说那是什么感觉吗？' | 过于宽泛缺乏聚焦 |
| 封闭式 | 可简答（是/否/事实） | '这种情况持续多久了？' | 连续使用→审讯感 |
| 祈使/间接 | 嵌入陈述中的邀请 | '告诉我更多的...' '我好奇...' | 过于模糊 |
| 投射性 | 邀请投射到假设情境 | '如果你能做任何事...' | 语境不当不自然 |
| 治疗性 | 产生改变而不只是收集信息 | 奇迹问题、刻度问题、例外问题 | 机械使用、缺乏真诚 |
| 奇迹问题 | 解决导向核心技术 | '假设今晚你睡着时奇迹发生...明天早上第一个小迹象是什么？' | 未充分跟进细节 |
| 刻度问题 | 数字量化主观体验 | '1到10，1是最糟，10是你的目标——现在在哪？' | 不解释刻度含义 |
| 外部化问题 | 将人与问题分离 | '"担忧"什么时候第一次进入你的生活？' | 感觉做作 |
| 例外问题 | 探索问题被管理好的时刻 | '什么时候问题本可能发生但没有发生？' | 没能跟进例外细节 |
| 预设性问题 | 嵌入来访者能力的假设 | '你用了什么应对技巧度过那段时间？' | 如果来访者没有成功体验则适得其反 |

**提问数量控制**：一次只问一个问题——多个问题同时问会让来访者困惑并稀释焦点

### 维度四：干预时机与深度

**评估要点**：
- 是否跟随而非引领（de Shazer的"跟随式引领"）
- 干预深度是否匹配来访者的当前状态
- 是否在共情之前纠正认知（CBT常见陷阱）
- 是否在建立联盟前进行深层工作
- 策略转换时是否有预告：'我想我们现在可以尝试...'

### 维度五：共情的循证路径

研究确认的共情促进积极结果的四个路径（Sommers-Flanagan）：
1. 改善治疗关系
2. 促进矫正性情感体验
3. 促进来访者自我探索（言语、情感、认知三个层面）
4. 促进来访者自我愈合

Greenberg et al.（2001）对47项研究、3000+来访者的元分析：共情与结果相关r=0.32——共情解释约10%结果方差，堪比或超过特定干预效应。

## 常见技术失误检测

| 失误 | 表现 | 改善方向 |
|------|------|---------|
| 审讯式提问 | 一连串封闭式问题 | 用一个开放式问题替代3个封闭式问题 |
| 过早安抚 | '会好的''别担心'直接关闭探索 | 先共情再回应：'你现在感觉非常艰难' |
| 过度解释 | 对每个行为都解读为深层冲突 | 有时一杯水就是一杯水 |
| 追随不够 | 在来访者还没说完时转换话题 | 言语追踪：回到来访者上一句话的核心 |
| 多问题轰炸 | 一次问三四个问题 | 一次一个问题，等待回应 |
| 缺乏转换告知 | 突然从共情切换到建议 | '我想基于刚才的讨论做一些补充...' |
| 以技术回避情感 | 咨询师不自在时过度使用技术 | 觉察自己的不自在，回到共情 |
| 在共情前纠正认知 | '你想错了'→来访者感觉不被理解 | 共情在前，认知探索在后 |
| 苏格拉底式审问 | 一连串问题让来访者感到被审讯 | 合作性探索：你也好奇，不是审问 |

## PETS编码系统（Milne & James, 2002）

评估督导者行为的13个可观察类别，也适用于反观受训者对来访者的行为：

| 行为 | 描述 | 示例 |
|------|------|------|
| 组织/管理 | 结构化流程 | '我想今天涵盖X' |
| 倾听/观察 | 积极倾听关注 | 非言语关注 |
| 支持/鼓励 | 言语/非言语安抚 | '这很有趣' |
| 总结 | 澄清联系 | '让我确认我是否理解' |
| 给予反馈 | 具体正/负面反馈 | '你设置这个的方式非常好' |
| 收集信息 | 询问事实 | '她多大了？' |
| 检查知识 | 监测/评估能力 | '在这里你会怎么做？' |
| 挑战 | 促使重新思考 | '你还能怎样处理？' |
| 告知/指导 | 提供说教信息 | '处理这种情况的方式是...' |
| 示范/体验 | 积极能力发展 | 示范、角色扮演 |
| 自我表露 | 透露新信息 | '这类个案很难处理' |
| 表达分歧 | 负面反应 | 言语纠正 |
| 个案示例 | 使用自身案例 | 来自受训者的案例 |

## 文化考量

- 非言语出席行为因文化而异 — 直接眼神接触在某些文化中被视为不敬
- 声音特征在不同文化中被不同解读 — 一种文化中的"温暖"可能是另一种文化中的"过于亲密"
- 提问的直接程度需考虑文化背景 — 某些文化中直接提问被视为无礼
- "应该"陈述在某些文化中可能是正常的文化义务而非认知歪曲
- 反映技术需适应文化表达方式 — 某些文化中直接的情感反映可能让来访者不适

## 自我觉察清单

- 受训者当前的技术水平是什么层次？我在使用发展性合适的标准吗？
- 我是否在以自己的理论取向偏好来评判受训者的技术选择？
- 受训者是否在回避某种技术（如情感反映）？这反映了个人因素吗？
- 来访者对受训者干预的反应 — 这是评估技术质量最重要的数据来源
- 我的反馈是否平衡 — 不只指出问题，也包括肯定做得好的一面？

## 与其他技能的整合

- 与alliance-monitoring：过程质量不能脱离联盟质量单独评估 — 技术再准确，如果联盟薄弱也无效
- 与countertransference：技术偏离往往与反移情有关
- 与pattern-recognition：技术失误模式提示需关注的发展领域
- 与clinical-interviewing：直接使用临床面谈的具体技术标准进行评估
