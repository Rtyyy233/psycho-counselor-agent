# 临床面谈核心技术（Clinical Interviewing）

参考来源：Sommers-Flanagan & Sommers-Flanagan 第4版 第2章（基础与准备）、第4章（倾听技术）、第5章（提问与指导性行动技术）、第6章（循证关系变量）、第8章（精神状况检查）、第10章（诊断与治疗计划）、第11章（与多样化和困难来访者工作）

## 核心立场

临床面谈是一种**有控制的专业关系情境**。咨询师与来访者之间建立积极而尊重的职业关系，通过言语和非言语互动，运用主动倾听技能和心理学知识来评估、理解和帮助来访者达成共同确立的目标。

四个核心因素：积极尊重的职业关系、双方协同确立的目标、言语与非言语互动的整合、文化背景和人格风格的影响。

**根本平衡**：咨询师是临床过程的专家，来访者是自己生活经验的专家（de Shazer）。

## 贯注与倾听技术（Attending & Listening）

### Ivey微技能层级模型

```
出席行为 → 提问 → 鼓励 → 重述/释义 →
情感反映 → 总结 → 聚焦 → 面质 →
解释 → 信息给予/教导
```

### 非指导性到指导性的连续体

```
沉默 → 重述 → 澄清 → 情感反映 → 总结 →
情感验证 → 解释性情感反映 → 解释 → 重构 → 面质
```

### 出席行为（SOLER模型）

- **S**quarely face — 正面面对来访者
- **O**pen posture — 开放的身体姿态
- **L**ean slightly forward — 微微前倾
- **E**ye contact — 适度的眼神接触（因文化差异而异）
- **R**elaxed — 放松自然

**语音特征（副语言）**：音高、语调、音量、语速、流畅度——是来访者先于内容接收到的信息，显著影响共情和可信度的感知。柔和而坚定，向来访者"学步"（匹配其语音风格以增进情感协调）。

### 五种必须避免的消极贯注行为

1. **过度点头** — 显得机械、不真诚
2. **过度"嗯哼"** — 20次/2分钟以上 → 表面化
3. **不当眼神接触** — 被审视感或回避（需考虑文化差异）
4. **鹦鹉学舌式复述（Parroting）** — 精确重复而不加处理，像被分析
5. **笨拙模仿（Mimicking）** — 机械镜像而非自然同步

### 重述/内容反映的四个层级

1. 基础重述 — 反映事实内容
2. 感官重述 — 强调感官细节（'当他说那句话的时候，你感觉血液涌上来了'）
3. 隐喻重述 — 使用来访者自己的隐喻（'就像被锁在屋子里出不来'）
4. 建构主义/解决导向重述 — 强调优势和例外

### 情感反映的两个层级

1. **初级共情** — 反映来访者明确表达的情感：'听起来你感到很沮丧'
2. **高级共情** — 反映来访者隐含的、未直接表达的情感：'我听到你说这些的时候，好像还有一丝不甘心在里面'

### 四种常见失败共情回应

1. "我理解你的感受" — 来访者怀疑：你怎么可能知道？→ 用反映代替声称
2. "我也经历过类似的事" — 焦点转移到治疗师 → 先共情
3. "天哪，那一定太可怕了" — 评判性 → 改为"听起来那对你来说非常可怕"
4. "哦，你真可怜" — 评价性赞扬 → 可能抑制袒露

### 沉默管理

- **四种沉默**：创造性沉默（内在加工）、保护性沉默（感到不安全）、焦虑性沉默（不知道说什么）、抗拒性沉默（不愿意参与）
- **关键原则**：不要急于填充沉默——沉默是来访者处理深层体验的时间
- **干预时机**：当沉默过长或来访者明显不适时，温和邀请——"刚才沉默的时候你心里在想什么？"

### 言语追踪（Verbal Tracking）

- 遵循来访者的叙事线而不转换话题
- 走神信号：跳到自己的想法或评价上，而非跟随来访者的内容
- 言语追踪显示"我在真正听你说话"——是建立联盟的基本功

## 提问技术（Questioning）

### 五条提问原则

1. 用开放式问题开启探索
2. 用封闭式问题获取特定、必要的事实
3. 避免引导性问题（"你不会真的认为那样对吧？"）
4. 避免听起来像指责的"为什么"问题
5. 跟随来访者的回应，而非遵循预设的问题议程

### 提问类型完整矩阵

| 类型 | 定义 | 示例 | 陷阱 |
|------|------|------|------|
| 开放式 | 不能以是/否回答 | '那是什么感觉？' | 过于宽泛 |
| 封闭式 | 可简答（是/否/事实） | '这种情况多久了？' | 连续使用→审讯感 |
| 祈使/间接 | 嵌入陈述中的邀请 | '告诉我更多的...' | 过于模糊 |
| 投射性 | 邀请投射到假设情境 | '如果你能做任何事...' | 语境不当 |
| 奇迹问题 | SFBT核心技术 | '假设今晚奇迹发生...明天早上第一个迹象？' | 机械使用 |
| 刻度问题 | 量化主观体验 | '1到10，你现在在哪？' | 不解释含义 |
| 外部化问题 | 将人与问题分离 | '"担忧"什么时候进入你的生活？' | 感觉做作 |
| 例外问题 | 探索问题被管理好的时刻 | '什么时候问题本可能发生但没有？' | 不跟进细节 |
| 预设性问题 | 嵌入能力假设 | '你用了什么应对技巧度过那段时间？' | 如无成功体验则适得其反 |
| 治疗前改变问题 | 发现已有变化 | '从预约到今天，你注意到什么变化了吗？' | 时机不当 |

### "为什么"问题的危险与适当使用

- **危险**：使来访者处于防御地位、要求解释行为、加重防御和理智化、损害情感协调
- **改进**：'为什么那样做？' → '是什么导致了那个选择？' / '帮我理解当时发生了什么'
- **适当使用**：情感协调良好时、希望来访者对某一模式或动机获得更深看法时

**禁忌**：避免问句加"尾巴"——将开放式问题变为封闭式（'你感觉怎么样——感到愤怒吗？'），极大限制来访者回答的详细程度

**数量控制**：一次只问一个问题——多问题轰炸让来访者困惑并稀释焦点

### 策略转换预告

从非指导性转向指导性时，告述来访者策略变化：
- '我们还有15分钟，我需要确认一些东西，可以吗？'
- '我想我们现在可以尝试一些不同的东西...'

## 循证治疗关系变量

### Rogers三核心条件的临床面谈应用

1. **表里如一（Congruence）** — 真诚透明，感受可见，不躲在专业面具后面
   - 实践边界：不意味着告知来访者所有个人想法，而是在互动中自然、诚实
   - 自我表露三原则（Falender & Shafranske）：为来访者利益、观察反应并引回焦点、避免无意表露
2. **无条件积极关注** — 珍视来访者作为人的全部，不因想法/感受/行为而有所保留
   - 间接传达优于直接声明（不说"我无条件接受你"——这听起来虚假）
   - 通过准时、记住偏好名称、专注倾听、追踪具体内容、共情回应间接传达
3. **准确共情** — 进入来访者的主观世界，同时保持"好像"的距离
   - Greenberg et al.元分析：共情与结果r=0.32（47项研究，3000+来访者），解释约10%结果方差

### 其他循证关系因素

- **工作联盟**（Bordin）— 目标一致、任务共识、情感联结
- **移情与反移情** — 移情是来访者将过去关系的感受/期望/防御投射到治疗师身上；反移情是治疗师的对应情感反应
- **治疗师可信度** — 通过环境（展示证书）、行为（帮助来访者重构成已成功治疗的问题）、一致性传达
- **信任度** — 通过礼貌介绍、清晰的保密说明、承认寻求帮助的困难、一致的专业行为传达

### 女权主义和建构主义的关系视角

- **互惠性（Mutuality）** — 共享权力、决策、目标选择和学习
- **赋权（Empowerment）** — 来访者将成长归于自己的努力和内在力量
- **协作共建**（Co-Construction）— "跟随式引领"（de Shazer）——跟随来访者的方式，同时引向新的可能
- **来访者作为专家** — 想法和任务应来自来访者，不是治疗师强加

## 来访者动机评估

### 三种动机分类（解决导向疗法）

1. **访客（Visitor）** — 被他人所迫参加治疗，无个人改变兴趣。应对：建立关系是挑战
2. **抱怨者（Complainant）** — 因个人痛苦和他人敦促参加。应对：有中等动机
3. **消费者（Customer）** — 为改变而消费的人。应对：高度动机，容易治疗

### 共同目标的确立

- 在最初会谈中帮助来访者识别他们认为哪里出了问题以及他们认为什么能起到帮助
- 避免目标不一致的三大来源：来访者动机/领悟力不足、治疗师动机/领悟力问题、社会文化差异
- **不充分评估的风险**：选择了不当治疗途径 → 可能伤害来访者；来访者感到被误解

## 精神状况检查（MSE）十项领域

1. **外观** — 外貌、年龄、修饰、着装
2. **行为/精神运动** — 过度（激越）或减少（迟滞）运动
3. **对检查者的态度** — 合作、敌意、怀疑、冷漠、讨好、急切、控制、消极、诚实、被动、诱惑、攻击
4. **情感与心境** — 情感=天气（可观察），心境=气候（自述）
5. **言语和思维过程** — 阻断、迂回、音联、思维奔逸、松散联想、缄默、新语词、持续言语、答非所问、语词杂拌
6. **知觉障碍** — 幻觉（五感中的虚假知觉）、错觉（真实刺激的误解）
7. **思维内容** — 妄想、强迫、恐惧；Robinson三阶段探索妄想法（建立关系→温和探索证据→试探性提供替代解释）
8. **定向与意识** — 人物、地点、时间、情境
9. **记忆与智力** — 数字广度、常识、抽象思维、判断力
10. **可靠性、判断力与自知力** — 四级自知力（完全否认→轻微觉察→外部归因→智力性洞察）

## 诊断和治疗计划的基本原则

### BASIC ID多维评估模型（Lazarus）

- **B**ehavior 行为 — 可观察的行为、习惯、回避模式
- **A**ffect 情感 — 情绪、心境、感受
- **S**ensation 感觉 — 身体感觉、紧张、疼痛、感官体验
- **I**magery 想象 — 心理图像、梦境、自我意象、身体意象
- **C**ognition 认知 — 思想、信念、归因、自我对话
- **I**nterpersonal 人际 — 社会关系、关系模式
- **D**rugs/Biology 药物/生物 — 物质使用、药物、身体健康、运动、饮食

### 循证治疗计划的四个证据来源

1. 来访者问题特征 + 疗效研究证据
2. 循证关系方法
3. 治疗师技能和专业知识
4. **来访者偏好**（来访者获得其偏好的治疗方式时有更好的结果和更低的脱落率）

## 自我觉察四领域

1. **客观/躯体自我意识** — 通过录音/录像观察自己的语音、表情和姿态
2. **心理社会自我意识** — "我的职业目标是什么？我为什么希望成为咨询师？"
3. **发展性自我意识** — 回忆生活中对今天发生关键影响的人和事
4. **文化自我意识** — 认识自己的文化/宗教/政治/性别背景如何影响对正常/异常的判断

**处理反馈的建议**：尽可能经常对自己的面谈录音录像、首先独自观看、向他人承认不适感、对积极和消极反馈保持开放、感谢给予反馈的人、学习放松技术

## 常见误区

| 误区 | 问题 | 纠正 |
|------|------|------|
| 审讯式提问 | 一连串封闭式问题 | 用一个开放式问题替代3个封闭式问题 |
| 过早安抚 | '会好的'关闭探索 | 先共情再回应 |
| 缺乏转换告知 | 突然从共情切换到建议 | 预告策略变化 |
| 以技术回避情感 | 不自在时过度使用技术 | 觉察不自在，回到共情 |
| 忽略来访者专家性 | 陷在专业身份中篡夺来访者权威 | 尊重来访者作为自己生活的专家 |
| 使用过多专业术语 | 来访者不能真正理解 | 用清楚直白的方式说明 |

## 与困难/非自愿来访者工作

### 改变的跨理论模型（Prochaska & DiClemente）

- **前沉思期** — 无改变意图 → 提升意识、提供信息
- **沉思期** — 矛盾中 → 探索矛盾、放大差异
- **准备期** — 即将行动 → 支持承诺
- **行动期** — 正在改变 → 实施策略
- **维持期** — 防止复发 → 巩固成果

### 动机性面谈核心原则（Miller & Rollnick）

- **精神**：协作（非对抗）、唤起（引出来访者自己的动机）、自主性（尊重来访者的选择权）
- **核心技能（OARS）**：开放问题（Open questions）、肯定（Affirmations）、反映（Reflections）、总结（Summaries）
- **关键过程**：让"改变的理由"从来访者口中说出，而非治疗师说出来
- **抑制"纠正反射"**（Righting Reflex）——治疗师自然倾向于"修复"来访者，但这典型地增加阻抗

### 对"阻抗"的重新定义

从经典弗洛伊德防御模型到**阻抗作为自然的情境反应**（de Shazer）。阻抗不是来访者的病理——它是来访者对感知到的威胁或强迫处境的一种正常的、适应性的保护性反应。

**策略性投降**（特别适用于青少年和非自愿来访者）：承认治疗师的有限权力和来访者的自主性——而非进行权力斗争。

## 文化考量

- 非言语出席行为因文化而异
- 提问的直接程度需考虑文化背景
- 自我表露期待因文化而异——某些文化群体期望更多治疗师自我表露以建立信任
- 奇迹问题需适配来访者的文化/宗教框架
- 心理教育需考虑文化解释模式（如某些文化使用灵性或躯体解释框架）
- 精神状况检查需考虑文化规范——某些文化中正常的精神体验不应被病理化

## 与其他技能的整合

- 与person-centered：面谈技术的基本立场就是人本主义的共情和接纳
- 与crisis-intervention：面谈中的MSE和风险评估是危机干预的核心技能
- 与alliance-repair：倾听和提问的质量是预防和修复联盟破裂的基础
- 与alliance-monitoring（督导）：督导主要使用本章的技术标准来评估受训者过程质量
